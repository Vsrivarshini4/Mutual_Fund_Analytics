# Mutual Fund Analytics

## About the Project

This project analyzes mutual fund data to understand fund categories,
risk levels, expense ratios, minimum investment requirements, and NAV data.

## Objectives

- Collect mutual fund data
- Clean and validate the data
- Analyze different mutual fund categories
- Study risk and expense ratios
- Analyze NAV data
- Generate useful insights from the data

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- SQLite
- Google Colab
- Jupyter Notebook
- GitHub

## Project Workflow

Data Collection → Data Cleaning → Data Validation → Data Analysis → SQL Analysis → Insights

## Project Status

Python analysis, NAV analysis, data validation, visualization, and SQL analysis completed.
